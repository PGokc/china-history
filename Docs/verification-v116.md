# 1.16 验证记录

## 本轮判断

汉代已有完整帝序、六十位人物、五类事件、十二项遗珍和六处帝陵。明显缺口不是继续堆数量，而是朝代总览仍是四段提纲，无法解释西汉、新莽与东汉之间的中断和重组，也没有把财政、边疆、经学、豪族及普通编户连接起来。

## 内容调整

- “汉承秦制，不等于照抄秦朝”解释郡国并行、战后恢复、宗室与功臣安排，以及中央收紧诸侯权力的长期过程。
- “扩张、财政与道路是一套相连的问题”连接匈奴战争、河西经营、五铢钱、盐铁政策与悬泉置邮驿劳动，并区分西域关系和内地郡县。
- “经学如何进入国家，也如何保持争论”避免用“独尊儒术”概括全部汉代知识，保留不同学派、师法和出土知识文本。
- “编户齐民之下，社会并不整齐”说明户籍治理、经济分化、流动职业和豪族网络；明确马王堆列侯墓不能代表普通家庭。
- “新莽中断与东汉崩解不能只怪宫廷”并列继承、改制、灾害、羌战、灾疫、流民和地方军事化，不以外戚与宦官包办解释。

## 自动门槛

- 数据版本 90 固定五篇顺序，总览不少于 300 个汉字，每篇不少于 220 个汉字。
- 检查郡国并行、悬泉置、盐铁会议、马王堆、王莽和黄巾起事等连接点，并要求保留贵族墓、边疆控制与知识史的证据边界。
- UI 测试从汉概览进入独立导读，滚动到第五篇和“资料与出处”，复查入口层级与页面末尾安全区。
