# 1.13 夏商内容与阅读层级验证

## 目标

按“从远到近”的顺序进入成文历史，不把夏商写成传说故事列表，也不因为材料有限而只保留短摘要。朝代详情先回答时代位置和基本格局，五篇深层内容进入独立专题页。

## 夏代

- 分开考古材料、传世文献和王朝对应解释，避免循环证明。
- 说明传统十七王次序的价值与精度边界，不虚构个人公历年。
- 用宫城、道路、作坊、墓葬和高等级器物解释二里头能够证明的社会组织。
- 并列呈现二里头—夏关系中的主要判断和证据门槛。
- 保留禹、少康、桀等历史记忆的影响，同时标示晚出人物和故事层累。

## 商代

- 区分传世王序与甲骨卜辞两种尺度的材料。
- 把郑州商城、偃师商城、小双桥、洹北商城和殷墟放入迁都与都邑变化中。
- 以动态区域网络解释商王权，不绘制后世式固定国界。
- 把农业、手工业、普通居住与人牲人殉纳入青铜礼器之外的社会史。
- 单列甲骨档案视角，说明同时代记录仍不等于全社会视角。

## 验证

- 数据版本87要求夏商各五篇正文、每篇至少200个汉字，并检查关键证据边界和来源完整性。
- UI 测试从朝代总览分别进入夏、商专题，检查首尾章节、资料入口和真机尺寸截图。
- 工程版本为1.13.0（113）。
