# 1.19 验证记录

## 本轮判断

南北朝已有九条平行帝序、九十四位人物、五类事件、十六项遗珍和四座证据有界的陵墓。明显缺口是朝代导读仍只有三句标签，无法解释九条帝序为何不能压成两条直线，也没有把北魏改革、建康城市社会、佛教赞助网络和六世纪再统一连接起来。

## 内容调整

- “九条帝序不是两条整齐平行线”解释同年并立、傀儡皇帝、受禅和反复边界。
- “北魏改革不是一场单向‘汉化’”连接平城建国、均田三长、迁洛、身份重组和六镇危机。
- “建康繁华背后是城市、州镇与编户社会”补入城市空间、财政赋役、门阀之外的人群和侯景之乱。
- “石窟与造像连接皇权、工匠和普通发愿人”区分皇家石窟、地方造像、题记赞助人与毁寺修复造成的材料边界。
- “六世纪竞争如何走向新的统一”连接东西魏、北齐北周、军府重组、南梁崩解及隋灭陈，拒绝结果论。
