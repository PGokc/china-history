# 1.21 验证记录

## 本轮判断

唐代已有完整帝序、六十八位人物、十座证据有界的帝陵、五类事件及多组宫廷人物、基层文书和物质文化专题。明显缺口是朝代导读仍只有“盛唐、安史、晚唐”三句，无法解释建国与统一的时间差、武周的制度位置、繁荣背后的身份差异和安史以后长期转型。

## 内容调整

- “建国、统一和贞观秩序不是同一时刻”区分617年起兵、618年建国、628年前后统一与626年继承重组。
- “律令、土地、赋役和科举都有执行边界”连接三省六部、田令、户籍、租庸调、科举与家庭身份，区分法令和现实。
- “武周是国家重组，不只是女皇传奇”并列宗室、武氏、旧族、科举官员、告密系统、洛阳礼制与宗教合法性。
- “开放帝国由许多城市、道路和不平等身份组成”区分真实人口流动、贵族墓葬表达和诗歌城市想象。
- “安史以后是结构转型，不是一百五十年连续衰败”连接盐利、漕运、两税、神策军、不同类型藩镇与唐末军阀化。

## 自动门槛

- 数据版本 95 固定五篇顺序，总览不少于 400 个汉字，每篇不少于 230 个汉字。
- 检查 617、626、628、690—705、755—763、780、875、907 等节点及两税法、神策军、河朔三镇等连接点。
- 明确禁止把建国归于太宗一人、把三省六部视作现代部委、把科举等同现代公平考试、把武周称作全民女性解放、把墓俑当人口统计、把所有藩镇称为独立或把唐史写成线性盛衰。
- UI 测试从唐概览进入独立导读，滚动至第五篇和“资料与出处”，复查入口层级与页面末尾安全区。
