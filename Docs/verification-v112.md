# 1.12 内容与交互验证

## 本次目标

史前首页继续以可拖动年代的地图为第一视觉层，不恢复重复的概览、静态地图或冗长遗址卡片。在地图控制与21处遗址导览之间增加单一的“理解史前中国”入口，让用户可以先建立时空感，再选择宏观阅读或具体遗址。

## 内容标准

- 五篇宏观长读分别讨论早期人类证据、现代人扩散、农业形成、区域社会复杂化与考古方法。
- 明确区分化石、石器、地层、测年、古DNA等材料能回答的问题，不把早期石器直接归给未经确认的人种。
- 不把制陶、定居与农业写成同时发生的单一革命，也不把考古学文化直接等同族群或王朝。
- 保留测年误差、样品保存、复原图性质与“最早”纪录会被新发现修订等证据边界。

## 自动验证

- `python3 scripts/validate_content.py` 检查五篇正文的长度、关键方法概念、出处引用和内部文案泄漏。
- `testV112PrehistoryMacroReadingIsDiscoverable` 从朝代首页进入史前地图，滚动找到宏观专题，检查首尾章节、资料入口和页面截图。
- 工程使用 1.12.0（112）生成并在真机尺寸模拟器编译、运行。

## 仍有边界

史前材料会随新发掘、测年和古DNA研究变化。应用提供的是经来源约束的学习框架，不把当前分期或个别“最早”发现包装为永久定论。
