# 史迹宏观产品审视（0.70）

## 当前阶段判断

史迹已经拥有 925 位人物、1697 项事件、258 项遗珍、82 处陵寝、882 篇长读和 872 条来源。主要问题不再是单一朝代缺少若干条目，而是内容规模、来源层级和学习入口之间尚未完全匹配。

0.70 先解决影响范围最大的可发现性问题：在不改变“朝代、帝序、家族、遗珍”底部结构的前提下，为四个主页面增加全局检索。检索覆盖人物、长读正文、事件、遗珍、陵寝、朝代、史前遗址与周代专题，并直接进入既有详情页。

## 后续优先方向

### 一、从条目数量转向在位脉络质量

- 目前仍有 77 个在位脉络只有两项事件，其中一部分是史料极少或在位极短的君主，不应为了统一数量强行补齐。
- 汉代大部分帝王虽然已有完整长读，但“当朝人物”和事件入口仍偏薄，应优先把现有七十余项汉代事件准确接回对应在位阶段。
- 唐武宗、宣宗、哀帝，宋钦宗、端宗、赵昺，以及数位元代短朝君主仍需要检查人物与事件入口。短朝应解释权力结构与前后承接，不机械追求五类事件齐全。
- 夏、周等早期王序的政治事件比例很高。后续补充经济和社会内容时必须依靠考古、铭文与制度研究，不能给证据不足的个人王年附会具体事件。

### 二、区分“家族记录”与“完整人物专题”

- 当前有 43 位人物没有独立长读，多数是为世系完整而保留的祖先、早夭子女或后妃。
- 不宜把每一个世系节点都扩写成同样长度的文章。应在界面上明确区分“家族记录”和“人物专题”，让资料较少者仍有清楚的身份、关系与来源说明。
- 值得优先补为完整专题的缺口包括秦庄襄王、赵姬，明代马皇后、朱标、朱高煦、张士诚、韩林儿等。清代早夭皇子和后妃应先完善关系记录与来源，资料足够后再决定是否扩写。

### 三、升级来源层级表达

- 872 条来源中，459 条为维基文库等平台上的古籍开放转录。它们适合核对原文，但不是文博机构或学术机构发布的数字资源。
- 现有内容已经在新增条目中说明“非官方平台”，下一步应给来源建立统一类型：正史与古籍转录、博物馆与文物机构、考古报告与研究机构、现代学术研究。
- 同一结论尽量同时提供原始史料和现代研究解释，尤其是人口数字、战果、灾害死亡、陵墓归属与器物定名。

### 四、建立跨朝代专题学习路径

- 全局检索解决“我知道关键词，怎样找到它”的问题；尚未解决“我想系统学习一个主题，从哪里开始”。
- 可以逐步建立财政与税制、交通与水利、城市生活、疾病与救济、女性与知识、边疆与互市等专题路径。
- 专题路径应先给概览，再按时代展开，并复用现有人物、事件和遗珍，不新增重复正文。

### 五、继续改善个人学习体验

- 增加本地收藏、最近阅读和跨文章续读列表，不需要账户和云同步。
- 朗读功能仍需在真实 iPhone 上检查普通话音色、锁屏控制、页面切换停止和长文续读。模拟器只能验证状态逻辑，不能替代听感测试。
- 长文章可以增加章节阅读时长和已读标记，但应保持页面克制，避免进度胶囊和装饰控件堆叠。

### 六、图像与地图保持证据优先

- 363 位帝王与王序人物中只有 46 位具有可靠或明确标注为后世宫廷像的画像。无可靠图像者继续使用文字布局，比使用来历不明的网络肖像更合适。
- 现有疆域图适合解释政权格局；后续可以为重要战争、迁都、交通与遗址增加专题地图，但不应把不确定边界绘成精确国界。

## 建议推进顺序

1. 梳理汉代在位事件入口，并修复已有内容未被皇帝页发现的问题。
2. 为来源增加统一类型和证据层级，同时逐步替换可找到官方版本的古籍链接。
3. 建立第一个跨朝代专题路径，优先选择“交通、水利与国家治理”。
4. 补齐秦庄襄王、赵姬、马皇后、朱标等具有独立历史作用的人物专题。
5. 增加本地收藏与最近阅读，再进行一次真实设备朗读审查。
