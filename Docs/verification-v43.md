# 史迹 0.43 内容与验证记录

版本：0.43.0（43）；内容格式版本25。基线：main / 8f865d9 / 0.42。

## 本轮目标与覆盖边界

明清继续补政权转折与经世思想；唐宋元按完整在位序列建立人物、长读、在位人物、事件、家族与遗珍入口。帝序共79位皇帝、83段在位：明16位17段，清12位12段，唐及武周22位24段，宋18位18段，元11位12段。辽、西夏、金的代表君主及1271年以前蒙古大汗为独立人物，不混入宋帝或元帝序。

明清新增郑成功、吴三桂、黄宗羲、顾炎武、王夫之，17项事件及《明夷待访录》《日知录》专题。三位学者按明遗民与同时代人物关联，不伪装成清朝在任官员。吴三桂归清发生在崇祯死后；康熙亲政、三藩、郑氏海上政权分别叙述。

唐代从建唐到唐亡，另补李建成、太平公主、李白、玄奘，贯通政治、军事、财政、诗歌与译经。武周单列，中宗和睿宗复位分别列段；武则天、少帝、哀帝的通行称谓不充作庙号。敬宗遇害按公历827年处理。太宗的玄武门经历属于高祖在位期间。

宋代覆盖北宋、南宋与辽夏金交往。孝宗对高宗的嗣继关系与亲生父系分开，英宗等的非直系继承不依帝序伪造父子关系。

元代从1271年国号元至1368年退出大都；忽必烈1260年汗位与元朝年界分别说明。两都之战并立争位、文宗复位分段，幼帝诏令与太后、大臣主持朝政分开。两位伯颜明确区分。起辇谷只做史料与考古边界专题，不虚构个人墓址。

## 阅读与导航

- 朝代概览新增帝序、家族、思想与遗珍三个入口，底部固定朝代、帝序、家族、遗珍。
- 当前朝代选择持久化，五朝的标题、人物归属与遗珍筛选独立。
- 无可靠画像时使用文字布局，不生成历史肖像或展示空白画框。
- 无已核查陵寝记录的朝代隐藏陵寝分类。乾陵两条人物记录指向同一座合葬陵，不计作两处遗址。
- 嗣父的子女列表显示嗣子，不沿用生父家的排行；此修复也覆盖弘曕出继允礼。

## 校验方法

内容脚本检查ID唯一、引用闭合、家族无环、人物归属、完整在位段、帝王文章与当朝人物文章、事件在位时间、章节入口、思想遗珍关联、庙号和产品内部文案。机械检查只能发现结构问题；具体史实另按逐朝研究记录的原文核查。

新增20位核心帝王长读至少1200汉字，其余新增帝王至少650汉字，重要人物独立文章至少500汉字并分节。新增遗珍与思想专题正文至少180汉字，按背景、内容与证据边界分段。字数仅作为避免薄弱卡片的最低检查，不代替来源与史实审读。

## 尚存限制

这是从明清专门内容扩为五朝系统阅读的一次扩充，并非完整通史百科。辽夏金目前只有代表君主和交往事件，未建各国完整帝序；唐代另立者李煴、李裕在历史叙述中说明，未列独立帝序。新朝代的地方社会、女性人物、边地交流、文物与陵寝仍有可继续扩充之处。唐代陵寝目前只有乾陵，宋元未用未经核清的位置填充地图。

来源中使用古籍公开数字转录以便追索卷次，仍须留意异体字、断句与官修史评价的局限；宗教感应、宫廷传奇和未经独立印证的死因不作为定论。
