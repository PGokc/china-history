# 0.70 验证记录

## 功能

- 四个底部主页面均提供“全局检索”入口，底部顺序保持为朝代、帝序、家族、遗珍。
- 检索范围包括人物基本资料与长读全文、历史事件、遗珍、陵寝、朝代、史前遗址和周代专题。
- 人物结果显示所属朝代与身份，事件显示年代与分类，遗珍和陵寝保留类型信息。
- 搜索结果使用字号、字重、颜色和留白分层，没有增加分类胶囊、箭头或装饰性圆点。

## 验证

- `python3 scripts/validate_content.py`：通过。
- `python3 scripts/test_reader_logic.py`：13 项回归测试通过。
- iPhone 17 模拟器编译：通过。
- `MingJiUITests.testV70GlobalSearchCrossesContentTypes`：通过。
- UI 测试确认四个主页面均可进入检索；“营造法式”同时返回事件和遗珍并可打开遗珍详情；“高骈”从明朝上下文也可跨朝代打开人物详情。
- iPhone 尺寸截图复查：搜索栏、结果标题、摘要、键盘与滚动区域层级清楚；键盘出现时结果仍可滚动，不与底部标签栏叠加。

## 限制

- 当前检索在本地内存中完成，数据规模仍适合即时匹配；若长读继续大幅增长，应建立预计算索引并测量旧设备输入延迟。
- 检索提供直接查找能力，跨朝代的系统学习仍需要独立的专题路径。
