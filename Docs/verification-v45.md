# 0.45 唐宋帝王画像核查

核查日期：2026-09-20。

## 本轮范围

- 唐朝帝序加入唐高祖、唐太宗、唐玄宗三幅国立故宫博物院藏帝王图册图像。
- 三幅唐帝像统一标为“后世宫廷像”。故宫研究已明确唐代帝王真容原迹无一存世，不能把后世摹绘当成本人写生。
- 宋朝帝序加入《宋代帝半身像》册中从宋太祖至宋度宗的十五幅图像，统一标为“南薰殿旧藏”。图像来自馆方 IIIF，详情页保留作品、重装年代、收藏机构与来源。
- 宋恭帝、宋端宗、赵昺不使用来源薄弱的网络画像，继续采用文字帝序。

## 资料依据

- 国立故宫博物院《历代帝王半身像》册唐高祖、唐太宗、唐玄宗分件页。
- 国立故宫博物院《宋代帝半身像》册及十五件分件页。
- 故宫博物院关于南薰殿旧藏历代帝后像的研究，用于区分唐代后世摹像与宋代御容传承。
