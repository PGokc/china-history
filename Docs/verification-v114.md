# 1.14 验证记录

## 本轮目标

按“从远到近”的内容主线深化周代，但不重复现有 25 个“周代人物与思想”专题。朝代导读负责解释西周至战国的长期结构变化，人物专题继续承担具体人物、学派和政治实践的深入阅读。

## 内容调整

- 周代总览扩展为三层：西周王权及其材料、平王东迁后的政治重组、战国国家与社会变化。
- 新增长读“王年与证据边界”，区分金文、传世文献与现代断代重建，并说明前 841 年以前绝对纪年的不确定性。
- 重写“封邦不是静态地图”，将封国解释为宗族、军事、交通、贡纳和资源关系构成的动态网络。
- 新增“东迁究竟改变了什么”，同时呈现王室资源收缩、礼制名分延续和春秋霸政形成，不把东迁写成制度瞬间断裂。
- 新增“列国怎样成为战国国家”，串联县与官僚、法律、赋役、军队、市场及各国变法的差异和社会代价。
- 扩展“礼器之外的人群”，纳入农业、手工业、士兵、女性、俘虏、迁徙与材料可见度问题。

## 事实边界

- 西周金文属于接近事件的第一手材料，但仍是贵族选择性纪念，不是完整编年史。
- 前 841 年以前王年采用常见断代框架，不宣称为无争议的出土年表。
- 春秋“五霸”在不同古籍中名单不一，正文不使用唯一固定名单。
- 铁器、牛耕和市场是转型条件，不写成单一技术决定论；六国制度也不描述为统一复制秦制。
