# 史迹 0.44：三轮审视与修复

基线：main / 88ca88c / 0.43。版本0.44.0（44），内容格式版本26。

## 第一轮：内容排序与空白层级

发现：事件列表直接提取日期开头的数字，“17世纪中后期”被读作公元17年，“元末”“永乐初”被读作0年；部分没有家族或遗珍入口的人物长读仍显示空的“继续探索”。

修复：事件排序使用共享的EventChronology；完整年份自动解析，概括年代独立配置sortYear，相同位置以稳定ID排序，未知格式不再静默当作0。为7条已有事件补充编辑排序位置，原有日期文字、正文与来源不变。只有实际存在入口时才显示“继续探索”。

sortYear是列表中的编辑位置，**不是新增的历史断年，也不用于在位事件归属判断**。朱升方略置于1350年代后段，湘王改谥置于永乐开端；“17世纪中叶/中后期”置于1650附近，“17世纪后期”置于1670附近，“18世纪中后期”置于1750附近。宽泛年代与具体事件的细微先后不能由此推断。

此次复核了[故宫朱升词条](https://www.dpm.org.cn/lemmas/241419.html)和[《明史》卷117湘献王传](https://zh.wikisource.org/zh-hans/明史/卷117)的用语；后者只写“永乐初”，因此保持原标签，不把排序位置1403写成确定的改谥年份。

第一轮内容校验及模拟器编译通过；李善长长读页末回归1/1通过，并复查1178×2556截图，确认没有空标题、出处入口位于朗读栏上方。

## 第二轮：阅读进度与朗读起点

发现：按“离屏幕顶部最近的标题”保存进度，会在上一节尚未读完时提前记入下一节；目录返回开篇只清理持久化值，内存中的旧章节和朗读备用值仍可能保留。

修复：仅在章节标题达到阅读上缘后切换当前章节；开篇显式清空当前值和持久化值，朗读不再回退到旧resume。目录选择停止原朗读，等待用户主动播放。取消离开页面后尚未完成的恢复任务；语音自动切章期间不让滚动动画覆盖语音章节。目录的无障碍值说明当前阅读章节。

第二轮3/3 UI测试通过：重新启动恢复章节、暂停后调整朗读设置与切页、目录返回开篇后退出重进并从第一节朗读。实际截图复查开篇和换页后的停止状态。独立Swift回归覆盖长章节中间、章节边缘、开篇、文末、空布局和事件排序，共13项断言。

## 第三轮：触控、大字号与整合

出处链接最小点击高度从36提升到44pt；不可用的上下节按钮降低颜色强度，播放按钮的无障碍值说明将朗读的章节。截图发现半透明朗读栏会透出背后正文，改为不透明暖纸色背景。

大字号截图进一步暴露上下节符号会随字号增长、超过44pt按钮区域，现固定符号17pt并保留44pt触控区域。首次第三轮8项回归中7项通过，新增大字号用例因未先滚动目录菜单而失败；补充菜单滚动后重跑，不将首次失败隐去。

普通字号的44pt断言又发现Link外部frame并未改变其18pt无障碍/触控矩形。将布局与contentShape移入Link标签后复测，避免只扩大留白却未扩大控件。

检查331个人物、290篇长读、489项事件、177条亲属关系：未发现重复人物文章、重复亲属边、多个亲生父亲/母亲或parent字段与亲生父系矛盾。主内容库文案扫描未发现P0、开发要求、占位等内部措辞。本轮不增加内容条目。
