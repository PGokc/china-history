# 0.39 清朝人物与雍正家族核查

核查日期：2026-09-08。应用内容由 80 位人物、65 篇长读、179 项事件扩充至 102 位人物、72 篇长读、191 项事件。

## 本轮范围

- 雍正十位亲生皇子：弘晖、弘昐、弘昀、弘时、弘历、弘昼、福宜、福惠、福沛、弘曕。其中弘历已有记录，本轮补入九位兄弟。
- 六位生母：乌拉那拉氏、钮祜禄氏、李氏、耿氏、年氏、刘氏；另补雍正生母乌雅氏、果毅亲王允礼。
- 四位雍正朝大臣：张廷玉、鄂尔泰、年羹尧、隆科多；年遐龄用于明确年氏与年羹尧的兄妹关系。
- 新增七篇独立长读：弘时、弘昼、弘曕及上述四臣；早殇皇子与记录较少的后妃采用简明档案，未虚构长篇事迹或画像。
- 新增十二项事件，并将已有建储、改土归流、军机处与即位事件接入人物关系。
- 84 节旧字段 `eventLinks` 迁移为模型实际读取的 `events`。其中 33 节存在有效旧链接，共恢复 34 条此前未显示的事件入口。原 `events` 内容合并去重保留。

- 检查往来人物的显示方向，修正七组清代关系正反标签对调；将慈禧与奕譞之间误用的“姨母”改为姻亲，胤禵“晚年统兵”改为“康熙晚年统兵”。

## 来源及冲突处理

1. [《清史稿》卷214 后妃传](https://zh.wikisource.org/zh-hans/清史稿/卷214)：后妃位号、皇子生母、葬所。
2. [《清史稿》卷220 诸王传](https://zh.wikisource.org/zh-hans/清史稿/卷220)：十子、允礼与弘曕承嗣，弘昼政务及弘曕处分。
3. [《清史稿》卷165 皇子世表五](https://zh.wikisource.org/zh-hans/清史稿/卷165)：皇子封爵、世系及弘昼卒年。
4. [林姝《弘时与福晋合葬：清西陵阿哥园寝考析》](https://www.dpm.org.cn/Uploads/file/2025/01/06/1736130517OeoEusmYI260.pdf)，故宫博物院，《紫禁城》2024年第12期：十子表、弘时处分与恢复玉牒的档案研究。
5. [《皇朝通志》卷50](https://zh.wikisource.org/wiki/皇朝通志_(四庫全書本)/卷050)：耿氏谥号。
6. [《清史稿》卷288](https://zh.wikisource.org/wiki/清史稿/卷288)：鄂尔泰、张廷玉。
7. [《清史稿》卷295](https://zh.wikisource.org/wiki/清史稿/卷295)：年羹尧、隆科多。
8. 故宫人物资料与雍正、乾隆年表：与原典交叉核对；个别词条直接抓取失败时，检索返回仅作比对，关键争议不依靠检索摘要定论。

采用以下编辑判断，并在应用相应人物或来源说明中保留依据：

- 弘昼卒年采用世表的乾隆三十五年（1770），与永璧同年袭爵及现代研究相合；不采用旧传及故宫旧词条的1765。生年以康熙五十年说明，注明农历岁末生日跨公历1712年。
- 耿氏采用《皇朝通志》的“纯懿”，不沿用后妃传的“纯悫”，也不编造“先纯悫后改谥纯懿”的过程。
- 福惠排行在旧籍中不一，依林姝表一用“未列齿序”，在补记中说明差异。弘昐、福宜、福沛同样不强配数字；传统皇四子弘历、皇五子弘昼、皇六子弘曕保留。
- 弘时处分过程区分雍正四年谕旨与五年去世；不把赐死、服毒、替弘历清除对手作为定论。暂不将被命为允禩之子的惩罚性安排作为无时间限制的永久嗣父线。
- 弘曕姓名不误写弘瞻、弘适；生父母与嗣父并列。精确生日材料冲突，本轮只记1733—1765。
- 张廷玉进士年采用本传1700；故宫旧词条1697有异。军机机构形成不强写单一创立日，《明史》不归为个人独著。
- 年羹尧自裁在雍正三年十二月，已跨公历1726；隆科多1728年死于禁所，不写处死。罪名标明朝廷指控，不用影视灭口说解释。
- 鄂尔泰改土归流兼写征税、驻军与镇压代价；1755年撤出贤良祠，与配享太庙分清。

## 限制

本轮围绕雍正皇子、生母及关键朝臣扩充，未声称完整收录清代后妃、全部皇女或每朝所有重要人物。部分人物仍主要依赖《清史稿》，其政治评价、罪名及网络录文字误须持续与实录、玉牒和档案对读。无可靠画像者保留无画像状态。
