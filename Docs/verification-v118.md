# 1.18 验证记录

## 本轮判断

两晋已有西晋、东晋两条帝序，十五位皇帝、四十一位人物、五类八十项事件和十二项遗珍。明显缺口是朝代导读只有三句，无法解释西晋统一为何迅速瓦解，也把十六国、侨置人口、门阀政治和江南社会压缩成几个标签。

## 内容调整

- “西晋统一为何没有形成稳定交接”连接司马氏代魏、灭吴、宗王军权、八王之乱和社会危机，避免只怪皇帝或外部入侵。
- “西晋灭亡以后，北方不是历史空白”把十六国写成多个有制度与社会的政权，并区分古代政治身份与现代民族概念。
- “侨州郡县把迁徙变成行政现实”解释侨置、白籍与土断，说明迁徙对财政、土地和江南地方关系的影响。
- “门阀重要，却不是东晋政治的唯一发动机”并列皇权、士族、军府、北伐与地方社会。
- “清谈与书法之外，还有城市、生产和信仰”补充建康、青瓷、农业水运、佛道网络和普通人的材料边界。
