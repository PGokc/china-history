# 0.51 内容与验证记录

## 范围

三国阶段由只读概览升级为完整学习路径。曹魏五帝、蜀汉二帝、孙吴四帝按三个并行组呈现，避免把同时存在的政权排成一条继承线。曹操、孙坚等生前未在三国时期称帝者保留在人物与转折叙事中，不混入帝序。

本版新增五十一位三国人物、五十六项重大事件、十二项遗珍专题、两处带证据边界的陵寝，以及所有新增人物的分层长读。事件按政治、军事、文化、经济、社会五类组织，每类至少十项。走马楼吴简、正始石经、孙吴纪年青瓷、朱然墓漆器、曹操高陵考古等材料用于补充纪传史。

## 事实边界

- 惠陵采用文献与长期祭祀传统，未推测未经发掘的地下结构。
- 孙权蒋陵采用南京文保名称和大致区域，同时明确准确墓穴尚未确认。
- 曹操为东汉末魏王，虽被曹魏追尊，未列入三国实际称帝者序列。
- “桃园结义”“七步诗”等后世广传情节不作为无争议现场事实。
- 三国疆域为约262年的概略控制范围，军镇前沿、山地族群与短期占领不以现代边界理解。
