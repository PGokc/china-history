# 0.50 隋代内容与验证记录

## 范围

- 隋代成为可进入朝代，覆盖杨坚、杨广，以及617—619年长安杨侑、江都杨浩、洛阳杨侗三条重叠帝序。
- 新增25位隋代人物、42项事件、12项遗珍、2处有可靠依据的帝陵和25篇人物长读。
- 五类事件均不少于8项，并把制度、战争、物质文化和普通人承担的动员成本放在同一时代框架中。

## 史实边界

- 618年作为唐建立的常用断代点；杨侗政权延续到619年，产品明确说明地域并立，不把它们串成全国同步交接。
- 杨广即位疑案只陈述可确认的权力交接，具体谋害细节标为史料争议。
- 贡举写作逐步形成的选官机制，不使用“605年突然发明科举”的单线说法。
- 大运河区分早期河道、隋代贯通和后世续修，并同时呈现长期交通价值与当时劳役成本。
- 帝陵只收录身份有明确依据的泰陵与扬州曹庄隋炀帝墓；未核清者不凑数。

## 核心来源

- 《隋书》帝纪、食货志、刑法志、百官志、经籍志及相关列传。
- 《资治通鉴》卷185、186。
- 中国国家博物馆李静训墓白瓷、玻璃、玉器和金项链资料。
- 故宫博物院隋墓与制度研究、北京市文物局大运河资料、江苏省文化和旅游厅隋炀帝陵资料、杨凌示范区泰陵资料。

## 验证目标

- 内容引用、人物关系、事件时间、帝序边界与图片完整性校验。
- 编译并编译 UI 测试；在真机尺寸模拟器复查朝代概览、五段帝序、人物五类事件、长读、遗珍和出处末尾。
- 构建设备包、严格验证开发签名，并在设备在线时安装启动。
