# 1.17 验证记录

## 本轮判断

三国已有三条并行帝序、五十一位人物、五十六项事件和十二项遗珍，人物与战役入口充足。明显缺口是朝代导读仍只有四句短说明，用户难以理解三个政权如何渐次形成，战争如何依赖人口与后勤，以及基层行政和普通生活如何进入三国史。

## 内容调整

- “三国形成是一段过程，不是一个日期”从东汉末年权力重组讲到曹魏、蜀汉和孙吴先后称帝，并区分称王、追尊与实际即位。
- “名将身后，是粮道、人口与反复变化的前线”把战役放回运输、屯田、军户、地形、疫病和迁民条件。
- “十万余枚吴简，把国家还原成日常工作”连接户籍、田租、司法与基层书吏，同时限定为孙吴长沙地区档案。
- “战争年代仍有家庭、生产与知识生活”补充家庭负担、区域生产、器物、建安文学与墓葬材料的适用范围。
- “归晋结束帝号并立，没有抹平区域差异”区分灭蜀、晋代魏、灭吴三个节点，并分层处理《三国志》、裴注和后世文学。

## 自动门槛

- 数据版本 91 固定五篇顺序，总览不少于 300 个汉字，每篇不少于 220 个汉字。
- 检查220年、229年、走马楼、军粮、九品官人法与280年等连接点，禁止把一地档案、墓葬模型和文学形象当成全时代事实。
- UI 测试从三国概览进入独立导读，滚动到第五篇和“资料与出处”，复查入口层级与页面末尾安全区。
