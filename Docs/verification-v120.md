# 1.20 验证记录

## 本轮判断

隋代已有五位明确标注并立与短期统治边界的帝序人物、二十五位人物、五类四十二项事件、十二项遗珍和两座证据有界的帝陵。明显缺口是朝代导读只有四句标签，无法解释北周制度怎样转入隋、统一国家怎样运作，也容易把运河和战争写成单因兴亡史。

## 内容调整

- “从北周禅代到灭陈，统一分成许多步骤”连接辅政、北方战争、受禅、灭陈与江南后续整合。
- “户籍、土地、仓储和选官都要区分制度与现实”解释大索貌阅、输籍定样、田令、义仓、含嘉仓和贡举的执行边界。
- “都城与运河首先是国家物流网络”区分广通渠、通济渠、邗沟、永济渠和江南河，说明长期遗产与当时负担可以同时成立。
- “边疆经营既有战争，也有使节、互市与迁徙”补入突厥、吐谷浑、西域和高句丽的主动政治及跨区域工艺。
- “隋末不是一场起义或一次禅让”连接灾害、征发、精英分裂、地方武装及长安洛阳江都多中心交接。
