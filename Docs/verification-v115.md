# 1.15 验证记录

## 本轮判断

秦代已有 16 位人物、27 项政治军事文化经济社会事件、9 项遗珍和完整的秦始皇帝陵入口，核心人物长读也已具备基础深度。明显缺口不是继续堆人物，而是朝代总览仅有三段标签式说明，无法把人物、简牍、制度、器物和社会代价组织成学习路径。

## 内容调整

- 总览扩展为三层：战国秦国的制度积累、出土简牍呈现的帝国运行、统一工具与高强度动员共同造成的遗产和危机。
- “帝国从战国国家生长出来”说明统一并非制度从无到有，商鞅变法也不是一次完成全部秦制。
- “郡县国家怎样落到一座小城”使用里耶迁陵县档案解释职官、邮驿、仓储、户籍、田租与地方差异。
- “秦律不只是重刑故事”使用睡虎地秦简解释行政、市场、工程和办案，同时明确秦律不等同现代法治。
- “统一尺度如何改变日常”连接铜权、半两钱、书写与道路，呈现便利、计算和征发能力的双重作用。
- “高效网络为何迅速崩解”并列继承危机、持续动员、官僚内斗、军事失败和地方反抗；不把“大雨误期当斩”当作秦亡的单一答案。

## 自动门槛

- 数据版本 89 固定五篇顺序，总览不少于 300 个汉字，每篇不少于 220 个汉字。
- 检查喜、迁陵县、半两钱、扶苏、陈胜吴广等连接点，并要求保留“一个县不能代表全国”“不能等同现代法治”等证据边界。
- UI 测试从秦概览进入独立导读，滚动到第五篇和“资料与出处”，复查入口层级与页面末尾安全区。
