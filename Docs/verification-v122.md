# 1.22 验证记录

## 本轮判断

五代十国已经有十一条并行帝序、五十六位统治者、五类事件、区域人物和遗珍，但朝代导读仍只有三句，并以通识百科为唯一来源。用户能查到人名，却难以理解“北方五代”只是正统史排列、传统“十国”不是固定同时存在的十国，以及宋的建立和区域整合之间仍有十九年过程。

## 内容调整

- “五代、十国和辽是同时存在的多套政治中心”区分中原王朝序列、南方与河东政权、名义臣属和实际控制。
- “军镇国家不等于没有制度”连接节度使、禁军、州县、枢密院、三司、军饷和合法性建构。
- “南方不是一块安静而富庶的整体”分别说明江淮、两浙、福建、岭南、四川、湖南与江陵的经济和战争经验。
- “战争之外还有税户、市场、信仰和技术”使用赋役、市场、工匠、墓葬、寺塔和印刷材料恢复非宫廷社会。
- “宋的建立不是分裂在960年突然结束”把960至979年的战争、投降、谈判和制度接续分开。

## 自动门槛

- 数据版本96固定五篇顺序，总览不少于400个汉字，每篇不少于230个汉字。
- 检查907、923、936、947、951、960、965、971、975、978、979等节点及枢密院、投龙银简、北汉等连接点。
- 明确禁止把“十国”理解为固定十国、把军镇国家等同无制度、把吴越当作整个南方、把墓葬祭祀器物当作全社会快照、把宋初收军权写成简单反武或不说明统一范围。
- UI测试从五代十国概览进入独立导读，滚动至第五篇和“资料与出处”，复查入口层级与页面末尾安全区。

## 验证结果

- 内容校验通过：926人物、363位帝王、367个在位段、1791事件、82座陵寝、917条来源；V96五代十国宏观阅读专项通过。
- iPhone 15模拟器完整编译通过，版本号为1.22.0（122）。
- 新增五代十国宏观阅读UI测试1/1通过；旧有“并行帝序—朱温长读—《韩熙载夜宴图》—资料出处”回归路径1/1通过。
- 真机尺寸截图人工复查通过：入口摘要能在三行内建立五篇范围；第五篇长标题、正文和资料入口未被底部标签栏遮挡。
- 审计同时发现旧版部分非核心五代人物长读存在句子重复填充；不影响本轮宏观阅读路径，但在进入宋辽夏金之前必须专项清理，不能继续以总字数通过代替内容质量。
- 真机安装已实际尝试：先因系统磁盘仅余约259 MiB中断，清理旧版临时DerivedData和测试包后释放约10 GiB；随后`devicectl`仍能识别已配对iPhone，但Xcode目的设备列表未出现该手机。改用通用iOS设备构建时，短暂出现的签名身份已从用户钥匙串消失，最终检查为`0 valid identities found`且Xcode无可用开发者账户。因此本轮不能完成实体iPhone签名安装；模拟器构建、UI测试与截图验证均不受影响。
