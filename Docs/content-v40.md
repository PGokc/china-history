# 0.40 明清在位人物与事件扩充

本轮以明清28位皇帝为范围，逐帝整理重要人物和在位事件，并新增52位人物与52篇分节长读、60项事件。整库为154位人物、124篇长读、250项事件、278条来源、182条往来关系。原乾隆即位两条重复记录已合为一条，因此事件净增59。

## 内容与入口

- 皇帝概览的“当朝人物”进入独立列表，再进入人物概览、长读、事件与资料。
- “重大事件”默认使用人工复核的在位清单；“生平相关事件”保留即位前与身后联系。年份相交检查仅作机械兜底，不代替同年登基前后的人工判断。
- 英宗使用正统、天顺两段在位；泰昌立储、梃击、登基前罢税发帑、天启登极前移宫、乾隆退位后白莲教起事、溥仪伪满经历等不混入该帝在位表。
- 乾隆即位条目保留旧稳定ID并采用较完整叙述；郑和远航区分永乐六次与宣德重新下令，旧七次综合事件仍供生平阅读。
- 清代旧事件的28条模板影响说明改为具体后果；章节人物与事件按该章内容关联。

## 核查依据

主要使用公版《明史》《清史稿》具体卷目，并参考故宫、中国国家博物馆、中科院自然科学史研究所及原始文书。链接均保存在内容库；研究过程见同目录三份 research 文件。正史含史家立场，《清史稿》并非定稿；有异文和争议时明确区分，不采用神异、猎奇或未经证实的宫廷故事。

## 仍可扩展的范围

本轮建立逐帝可用的主线，不宣称穷尽明清史。地方社会、女性、普通民众与非汉族群体仍较少；明代张辅、蹇义、胡宗宪、俞大猷、宋应星，清代梁启超、丁汝昌、刘锦棠、黄兴等仍值得独立扩展。现有皇帝长文并未因本轮新增导航而声称全部逐句重校。

补充核读：《明史》卷218申时行传记万历十八年后“明年八月”的奏疏争议与去职，故新增1591年辞去首辅事件，链接申时行第三章与万历争国本章节。

界面复查另修正切换朝代后帝序保留旧滚动位置的问题：列表身份随朝代变化，同一朝代内返回仍保留浏览位置。
