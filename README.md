# 史迹

一款供个人学习使用的 iPhone 原生中国历史应用。当前版本为 **0.73**，最低支持 iOS 17。

## 当前内容

- 中国历史朝代总览，以及各时期的疆域与政权格局图。
- 可按时间拖动的史前遗址地图，收录北京人、蓝田人、河姆渡、良渚等遗址。
- 夏、商、周至秦、汉、三国、隋、唐、宋、元、明、清的帝王或传统王序；可考公历、断代方案、传世王表、复位与并立政权均按证据层级分开说明。
- 唐宋元明清皇室家族、重要宗室、将领、大臣和同时代人物网络；亲生、嗣继与礼制承继分别标示。
- 雍正十位皇子与六位生母、弘曕出继果亲王的关系；弘时、弘昼、弘曕及张廷玉、鄂尔泰、年羹尧、隆科多的独立长读。
- 363位实际在位者、并立君主与传统王序人物均有“当朝人物”入口和事件清单；367段帝序明确区分可考公历、断代方案、传世次序、概括阶段与年代待考。
- 内容规模与逐朝覆盖见 [0.43 内容与验证记录](Docs/verification-v43.md)。
- 明清新增郑成功、吴三桂、黄宗羲、顾炎武、王夫之，贯通政权更替、三藩与明清之际思想。
- 唐代覆盖建唐至唐亡，宋代覆盖北宋与南宋，元代覆盖1271—1368；蒙古前史、辽夏金代表君主另以人物与事件衔接。
- 政治、军事、文化、经济与社会五类重大事件，附人物和阅读章节之间的链接。
- 有可靠依据的帝王画像、陵寝、器物、典籍、建筑及出处；新朝代无图人物采用文字布局，未核清的帝陵位置不标点。
- 明代程朱理学、阳明心学、泰州学派与晚明实学，清代经世反思、乾嘉考据、洋务、维新和清末新政等思想与变革专题。
- 《本草纲目》《天工开物》《天演论》典籍专题与作者相互关联，思想专题可以进入核心人物长读。
- 中文长文朗读、阅读进度和系统大字号支持。

## 工程结构

- `App/`：SwiftUI 源码、图片和当前内容库。
- `Design/Brand/`：当前品牌图标的高分辨率源图。
- `Tests/`：主要浏览路径与无障碍 UI 测试。
- `Docs/`：内容核查使用的原始资料及来源清单。
- `scripts/`：工程生成、内容校验、史料抓取与真机安装工具。

## 校验与运行

```sh
python3 scripts/validate_content.py
python3 scripts/test_reader_logic.py
python3 scripts/generate_project.py
open MingJi.xcodeproj
```

真机安装：

```sh
scripts/install_device.sh <已配对设备标识>
```

安装脚本只构建、验证开发签名、安装和启动，不会上传 TestFlight 或 App Store。

## 内容原则

历史叙述以博物馆、文物机构、公开史料和专业研究为优先来源。事实与评价分开呈现；存疑的画像、数字或因果关系明确说明依据和边界。界面只显示用户需要的历史内容，开发说明和内部进度不会进入产品文案。
